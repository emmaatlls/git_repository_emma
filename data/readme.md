### Git Data repository - Emma's Bachelor Thesis

### Folders
- `GEMS_generation_curation` contains the genome files, draft and curated models
- `communties` contains simulation results (growth-results) and drop-out communities
- `media_creation` contains raw metabolomic files and the created media csv
- `plotsnfigs` contains figures and other plots shown in the thesis/defence


### Other Files
- `category_metabolites.csv` classifies metabolites based on their BiGG identifiers into metabolite classes
- `SynComs_taxonomy.csv` contains taxonomic information required by MICOM to create communities
- `translate_tobigg.csv` translates compound names from metabolomics data to BiGG identifiers, used in medium creation
