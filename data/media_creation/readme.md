# ReadMe Media creation
- `media_barley - 7dpi_AF_mock` is the raw metabolomics file from the barley root apoplast
- `created_media` contains the completed apoplast media
    - `media_barley - 7dpi_AF_mock_translateandclass`: BiGG translated and tiered metabolomics file
    - `HvSC1_af7` and `HvSC2_af7`: completed medium for each community (done with MICOM and `media_barley - 7dpi_AF_mock_translateandclass` as input), gorwth rate 1
    - `af_diff_growth`: combined media for different growth rates as indicated by cxix27 (x = community growth rate, therefore individual growth rate = x/size community). **THE MEDIUM USED FOR ALL SIMULATIONS IS `combined_af7_c1i127`.**
